## 디버깅 요청 4요소 / Four parts of a debugging request

- 증상 Symptom: 과목 찾기 탭에서 [담기]를 누르면 서버에는 저장되는데(`POST /api/cart` → 201), 오른쪽 미니 시간표와 담은 과목 목록이 비어 있고 버튼도 [담기] 그대로다.
- 재현 Steps:
  1. `backend` 폴더에서 `python -m scripts.init_db --reset` → `python -m scripts.import_csv --captured-at 2026-09-20` → `python run.py`
  2. `http://localhost:5000/#search` 접속
  3. `데이터베이스`(월·수 10:00–11:00) 줄의 [담기] 클릭
  4. 같은 버튼을 한 번 더 클릭
- 기대 Expected: 미니 시간표에 월·수 10:00–11:00 블록이 생기고, 담은 과목 카드가 1개 보이고, 버튼이 [빼기]로 바뀐다.
- 실제 Actual: 미니 시간표·목록에 변화가 없고 버튼은 [담기] 그대로다. 다시 누르면 `이미 담은 과목입니다.` 토스트(409)가 뜬다. → 서버와 화면의 담기 상태가 서로 달랐다.

## 데모 시나리오 초안 / Draft demo scenario
사용자: ICT융합학부(데이터,디자인) 화면 한개만으로 시간표를 짜고 싶다.
1. 접속하면 첫 화면은 빈 내 시간표 — `아직 담은 과목이 없어요` 안내 → [과목 찾아보기] 클릭
2. 과목 찾기 탭에서 `데이터` 검색 → 데이터베이스(2개 분반), 데이터시각화가 평점과 함께 표에 나온다
3. **데이터베이스**(월·수 10:00–11:00) [담기] → 오른쪽 미니 시간표에 블록이 생기고 버튼이 [빼기]로 바뀐다
4. 검색어를 지우고 **기계학습**(화·목 13:00–14:00) [담기]
5. **데이터시각화** 줄에 `시간 겹침` 표시, 담기 버튼 비활성, 경고문구가 뜬다 
6. 데이터베이스의 **다른 분반**(화·목 15:00–16:30) [담기] → `같은 과목의 다른 분반이 이미 담겨 있습니다.`
7. [내 시간표] 탭 → 블록 2개가 요일·시간에 맞게 보이고 `2과목 6학점`
8. 새로고침해도 시간표가 남아 있다 → × 로 기계학습을 빼면 격자·목록·학점이 함께 바뀐다
9. (실패 경로) `없는과목` 검색 → `조건에 맞는 과목이 없습니다.`
