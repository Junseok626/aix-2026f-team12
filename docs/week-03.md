## 1. 문제 후보 3개 / Three problem candidates

> 네 칸이 다 채워지지 않으면 아직 문제가 아니라 막연한 아이디어입니다.
> 사용자는 구체적으로 기입하세요.

| 네 요소 Four elements | 후보 A | 후보 B | 후보 C |
|---|---|---|---|
| 사용자 | 한양대학교 학생 | 팀플 과제하는 학생 | 쇼핑몰 및 웹사이트 사용자 |
| 상황 | 수강신청 | 팀플 기여도를 정량화 하고 싶을 때 | 웹사이트 및 쇼핑몰을 이용할 때 |
| 페인포인트 — 무엇이 **얼마나** | 정보가 흩어져 있음(강의평, 필수이수과목 등) | 누가 얼마나 기여했는지 수치화가 필요함 | 구매유도 및 광고가 자주 나옴 |
| 성공 기준 | 한 화면에서 강의평가와 커리큘럼을 비교하며 강의 선택 가능 | 팀플이 완료되었을 때 기여도 산출 | 구매유도 및 광고 요소 약화 |

**한 문장으로 / One sentence each** — 네 칸을 이어 붙여 소리 내어 읽어 보세요.
형식: **[사용자]는 [상황]에서 [페인포인트] 때문에 [손해]를 본다.**
읽었을 때 어색하면 그 칸이 아직 덜 채워진 것입니다.

- A: 한양대학교 학생들은 수강신청할때 수강과목에 대한 정보가 흩어져 있어서 불편함이 있다.
- B: 팀플 과제하는 학생들은 팀플 기여도를 수치화하여 나타내고 싶을 때가 있다. 정성적으로 판단하면 정확하지 않을 때가 있기 때문이다.
- C: 쇼핑몰이나 웹사이트에서 구매를 강요하는 광고 때문에 이용하기 불편하다.

> 무엇을 **만들지는 쓰지 않습니다.**  기능은 4~5주차에 정합니다. / Describe the problem, not the solution.

> 성공 기준은 지금은 말로 써도 됩니다. "몇 초 이내" 같은 정확한 문장으로 다듬는 것은
> 4주차에 EARS로 합니다. / Plain words are fine for now — we formalise these next week.

## 3. 확인할 가정과 확인 계획 / Assumptions and how to check them

> 지금 사실이라 믿고 있지만 아직 확인하지 않은 것을 적고, **어떻게 확인할지** 정합니다.


**먼저 고르세요 / Pick the right method**

| 방법 | 이럴 때 씁니다 |
|---|---|
| **인터뷰** | 물어야만 알 수 있는 것 — 기억, 판단, 겪은 일, 왜 그렇게 했는지 |
| **관찰** | 가서 보면 알 수 있는 것 — 줄 길이, 걸리는 시간, 실제로 하는 행동 |
| **기존 데이터** | 이미 어딘가 쌓여 있는 것 — 학사 통계, 게시글, 앱 리뷰 |
| **직접 해보기** | 우리가 재현할 수 있는 것 — 그 과정을 실제로 한 번 해본다 |

> *Don't interview for what you can observe.*

| # | 후보 | 우리가 사실이라 믿는 것 | 방법 | 누구에게 / 무엇을 | 담당 | 기한 |
|---|---|---|---|---|---|---|
| 1 | A | 학생들은 수강신청 때 여러 사이트(강의평, 학과 홈페이지, 커리큘럼)를 오가며 비교하느라 불편해한다 | 인터뷰 | 최근 수강신청 경험자에게 어떤 사이트를 몇 개나 오갔는지 |  |  |
| 2 | B | 조별과제에서 무임승차/기여도 불균형에 대한 불만이 흔하다 | 인터뷰 | 조별과제 경험이 있는 학생에게 무임승차를 경험한 적이 있는지, 개인별 기여도에 비해 받은 성적에 불만이 있던 경험이 있는지 |  |  |
| 3 | C | 다크패턴은 국내에서도 실제로 규제 대상이 될 만큼 문제가 된다 | 기존 데이터 | 공정거래위원회 다크패턴 가이드라인/제재 사례, 소비자원 신고 통계 조사 |  |  |

> **인터뷰를 쓴다면** 팀원 외 3명 이상,이 문제를 겪고 있는 당사자를 포함하세요.
> 3명은 **주제를 거르기 위한 최소치**입니다. 통계가 아닙니다.
> 3명 중 2명이 인정했다고 해서 "66%가 문제를 겪는다"고 쓰면 안 됩니다.
> 숫자로 주장하려면 훨씬 많이 필요합니다.(설문지를 통한 결과 도출) / Three people is a filter, not a statistic.

**지금은 어떻게 하고 있는가 / What do they do today?**

> 불편해도 사람들은 이미 나름대로 하고 있습니다. 예) 문제를 공유하고 싶은 문제가 있을때 카톡 전송, 엑셀 파일 메일로 보내기, 그냥 포기하기 — **도구가 아니어도 답입니다.**

- **지금은 어떻게 하고 있는가** (도구가 없으면 "그냥 포기한다"도 답): 후보 A - 여러 웹사이트와 파일을 켜놓고 비교 확인해가며 수강신청, 후보 B - 팀원 간 논의를 통해 각자의 참여도를 평가, 후보 C - 다크패턴으로 감춰진 정보를 찾느라 시간을 소비하거나 방법을 찾기 위해 시간을 더 씀
- **그래서 충분한가** — 충분하지 않다면 무엇이 부족한가: 후보 A - 충분하지 않음, 불필요한 시간 소비가 증가, 후보 B - 충분하지 않음, 개인 별 참여도가 정량화 되지 않아 참여도의 확실한 구분이 어려움, 후보 C - 충분하지 않음, 불필요한 시간을 소비하게 되고 금전적 손실이 발생하기도 함 


**인터뷰를 한다면, 물어볼 질문 3개 / If you interview, your three questions**

> 과거형으로. "쓰시겠어요?"(X) → "최근에 그런 적 있으셨어요?"(O)
> 미래 의향을 물으면 대부분 "네"가 나옵니다.

후보 A
1. 수강 신청할 때 몇 개의 사이트를 오갔는지?
2. 수강 신청할 때 짜증나는 순간은 언제였는지?
3. 수강 신청할 때 강의평을 확인하였는지?

후보 B
1. 조별과제에서 무임승차/기여도 불균형을 겪은적이 있었는지?
2. 조별과제를 하면서 자기평가/동료평가를 신뢰할 수 있었는지?


**관찰·데이터·직접 해보기를 한다면 / If you observe instead**
후보 A
- 무엇을 셀 것인가 (숫자가 나와야 합니다): 수강신청할때 몇개의 사이트를 오가는지 (몇 개)

후보 B
- 편집 이력을 가져와 주관적 판단과 정량적 데이터를 비교해 얼마나 차이가 나는지 (주관적 판단 - 정량적 데이터 수치)

후보 C
- 무엇을 셀 것인가 (숫자가 나와야 합니다): 다크패턴으로 인한 시정 사례 횟수
- 언제 어디서: 공정거래위원회 보도자료 조사
